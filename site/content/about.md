전북대학교 컴퓨터공학부에 재학 중인 **문도경**입니다.
팀 프로젝트에서 화면(프론트엔드)과 서버(백엔드)를 각각 맡아 서비스를 만들어 왔습니다.

## 사용 기술과 사례

| 기술 | 사용한 곳 |
|---|---|
| Express (Node.js) | [빨래집사](../projects/) 서버 — 센서 데이터를 받는 API와 세탁 상태 판단 로직 |
| Supabase (PostgreSQL) | 빨래집사 DB — 여러 기기에서 같은 데이터에 접근하기 위해 SQLite에서 전환 |
| Python | 스마트플러그 전력값을 주기적으로 읽어 서버로 보내는 스크립트 |
| React Native (Expo) | JBSW-NOW 앱 — 검색 화면, 알림 화면, 알림 설정 화면 |
| Git · GitHub | 팀 협업(브랜치·Pull Request), 이 사이트의 GitHub Actions 자동 배포 |

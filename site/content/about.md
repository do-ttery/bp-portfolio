전북대학교 컴퓨터공학부에 재학 중인 **문도경**입니다.
팀 프로젝트에서 화면(프론트엔드)과 서버(백엔드)를 각각 맡아 서비스를 만들어 왔습니다.

## 관심 분야

아직 한 분야로 정하지 않고 찾는 중이지만, 지금 가장 관심 있는 것은 **AI 에이전트와 함께 개발하는 방식**입니다.
JBSW-NOW에서는 화면을, 빨래집사에서는 서버를 맡았는데, 빨래집사에서는 기획과 규칙을 문서(`CLAUDE.md`)로 정해 두고 역할별 AI 에이전트가 그 문서대로 구현·검증하도록 작업 환경을 만들었습니다.
사람이 무엇을 정하고 AI에게 무엇을 맡길지에 따라 결과가 크게 달라지는 것을 경험하면서 이 분야에 관심이 생겼습니다.

## 학습 목표

이번 학기가 끝나면 **AI Agent Challenge 같은 부트캠프·챌린지에 한 번 더 참여**해, AI 에이전트와 함께 서비스를 처음부터 완성하는 경험을 다시 쌓는 것이 목표입니다.

- 다음 행동: 학기 중에 겨울방학 부트캠프·챌린지 모집 공고를 찾아 지원하기
- 다음 행동: 그 전까지 이 포트폴리오 사이트처럼 규칙 문서(`CLAUDE.md`)를 정해 두고 AI와 함께 작업하는 방식을 계속 연습하기

## 사용 기술과 사례

| 기술 | 사용한 곳 |
|---|---|
| Express (Node.js) | [빨래집사](../projects/) 서버 — 센서 데이터를 받는 API와 세탁 상태 판단 로직 |
| Supabase (PostgreSQL) | 빨래집사 DB — 여러 기기에서 같은 데이터에 접근하기 위해 SQLite에서 전환 |
| Python | 스마트플러그 전력값을 주기적으로 읽어 서버로 보내는 스크립트 |
| React Native (Expo) | JBSW-NOW 앱 — 검색 화면, 알림 화면, 알림 설정 화면 |
| Git · GitHub | 팀 협업(브랜치·Pull Request), 이 사이트의 GitHub Actions 자동 배포 |
